GIT WRAPPED - il tuo anno su GitLab, in stile Spotify Wrapped
==============================================================

L'app gira solo sul tuo computer e mostra solo il TUO wrapped, letto con il tuo token.
Non manda i tuoi dati a nessuno: il token resta nel file .env di questa cartella.

Serve solo Docker Desktop (Mac, Windows o Linux): https://www.docker.com/products/docker-desktop/


1) PROVA SUBITO LA DEMO (senza token)
-------------------------------------
Apri un terminale in questa cartella e lancia:

    docker compose up -d

Poi apri http://localhost:8080 nel browser. Vedrai il wrapped di una persona inventata.


2) CREA IL TUO TOKEN GITLAB
---------------------------
Su GitLab: avatar in alto > Preferenze (Preferences) > Token di accesso (Access tokens)
  - Nome: git-wrapped
  - Scadenza: breve (bastano pochi giorni)
  - Scope: solo "read_api"
Copia il token: GitLab lo mostra una volta sola.
Serve un token PERSONALE: i token di gruppo o di progetto vengono rifiutati.


3) METTI I TUOI DATI
--------------------
Rinomina "env.example" in ".env" (con il punto davanti) e compila:
  - GITLAB_URL   = indirizzo del GitLab aziendale
  - GITLAB_TOKEN = il token creato al punto 2
  - GITLAB_GROUP = facoltativo, il gruppo del tuo team
Su Mac/Linux i file che iniziano con il punto sono nascosti: nel Finder premi Cmd+Shift+. per vederli.
Da terminale: cp env.example .env


4) AVVIA CON I TUOI DATI
------------------------
    docker compose up -d --force-recreate

Apri http://localhost:8080. Il primo caricamento può durare qualche decina di secondi.
Se la pagina non si apre: docker compose logs api  (spiega cosa manca, senza mostrare il token).


COMANDI UTILI
-------------
  Fermare l'app:         docker compose down
  Aggiornare l'app:      docker compose pull && docker compose up -d
  Vedere i log:          docker compose logs


PRIVACY IN BREVE
----------------
  - Il token è di sola lettura e resta nel tuo .env.
  - Nessun database, niente scritto su disco: i dati stanno in memoria per 15 minuti.
  - Il calendario Outlook (.ics, facoltativo) viene letto solo dal browser.
  - Quando hai finito puoi revocare il token da GitLab.
